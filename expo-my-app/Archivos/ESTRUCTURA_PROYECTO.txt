1. COMPONENTE RAÍZ: App.jsx
================================================================================

Ubicación: ./app/App/App.jsx

Descripción Funcional:
  - Componente principal que gestiona el estado global de categorías y productos
  - Implementa la capa de API para comunicación con backend
  - Proporciona las funciones CRUD (Create, Read, Update, Delete) para categorías y productos
  - Maneja el ciclo de vida de la aplicación (fetch inicial de datos)
  - Envuelve toda la interfaz con ImageBackground (imagen de fondo: beans.jpg)
  - Implementa ScrollView para navegación vertical en dispositivos móviles

Objetivo Principal:
  - Centralizar la lógica de estado y gestión de datos
  - Actuar como contenedor de la interfaz de usuario
  - Comunicarse con API REST (https://jlorenzo.ddns.net/carta_restaurante)
  - Garantizar sincronización de datos entre componentes

Funciones Clave:
  - fetchCategorias(): Obtiene lista de categorías del API
  - fetchProductos(catId): Obtiene productos de una categoría específica
  - addCategoria(): Crea nueva categoría
  - editCategoria(): Actualiza nombre de categoría
  - deleteCategoria(): Elimina categoría
  - addProducto(): Crea nuevo producto en categoría
  - editProducto(): Actualiza producto
  - deleteProducto(): Elimina producto

Extensión Aproximada en PDF (APA):

  - Diagrama de flujo CRUD: 0.75 páginas
  - Código comentado: 1 página

RESUMEN ARQUITECTURAL
================================================================================

Patrón de Arquitectura: Component-Based Architecture (React)

Flujo de Datos:
  App.jsx (Estado Global)
    ├── State: [categorias, setCategorias]
    ├── Funciones CRUD: add/edit/delete
    └── Props Drilling → Conteiner.jsx → Category.jsx → Product.jsx

Niveles de Componentes:
  1. Nivel 0 (Root): GestureHandlerRootView → App.jsx
  2. Nivel 1 (Main): Conteiner.jsx (gestiona layout principal)
  3. Nivel 2 (Sections): Header, Category, Footer, Spacer
  4. Nivel 3 (Items): CategoryHeader, ProductList
  5. Nivel 4 (Individual): Product, AddProductForm, ButtonCategory
  6. Nivel 5 (Atomic): Button, FormInput, Spacer

Separación de Responsabilidades:
  - App.jsx: Lógica y estado global
  - theme.js: Estilos y tema global
  - Conteiner/: Organización de layout
  - Category/: Lógica de categoría y productos
  - components/: Componentes atómicos reutilizables

Responsividad:
  - Breakpoint: width < 600px → mobile
  - Breakpoint: 600px < width < 900px → tablet
  - Breakpoint: width > 900px → desktop
  - Implementado mediante Dimensions.get('window')

Total de Archivos: 14 archivos
  - 1 archivo TypeScript (index.tsx)
  - 1 archivo JavaScript tema (theme.js)
  - 12 archivos JSX componentes
